⚙️ Settings

💾 Backup & Restore

Data isi phone / computer ke browser mein save hota hai. Haftay mein ek dafa backup download kar lein — phone change ya browser clear honey par backup file se saara data wapis aa jayega.

📱 App Install Karein

Ye website ek downloadable app bhi hai — home screen par install ho jati hai aur internet ke baghair bhi khulti hai.

Android (Chrome): Upar “Install App” button dabayein, ya Chrome menu (⋮) → “Add to Home screen / Install app”.
iPhone (Safari): Share button → “Add to Home Screen”.
Computer (Chrome/Edge): Address bar ke right side install icon, ya “Install App” button.

⚠️ Danger Zone

Saare items aur entries saaf karke khali system karein, ya asal items list (stock 0) ke sath dobara shuru karein. Ye action wapis nahi hota — pehle backup le lein.
